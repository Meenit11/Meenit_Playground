How to Play

🎮 What's the Game?

Everyone answers the same question. Unique answers survive. Duplicates get eliminated!
Last 1-2 players standing win! 🏆

📱 Setup

  • Create Room → Get a 4-digit code
  • Share Code → Friends join on their phones
  • Start Game → Need 3+ players
  • One player becomes Game Master 👑 (controls the game)

🎲 How to Play

Each Round:

  • 📋 Question appears (e.g., "Name a fruit")
  • ⏰ Get ready → 3...2...1 countdown
  • ⏱️ Answer time → 10 seconds to type and submit
  • ⚠️ Once submitted, you can't change it!

📊 Review: See everyone's answers:
❌ Bob | (No Answer)
🟡 Alice | Apple ← Duplicate!
🟡 Charlie | Apple ← Duplicate!
✅ Diana | Mango ← Unique!

👑 Eliminate: Game Master picks who's out

🔁 Repeat: Until only 1-2 players remain

👑 Game Master Powers

  • ⏸️ Pause → Stop timer
  • 🔄 Reset → Restart with 10 seconds
  • ⏭️ Skip → Jump to results
  • ✏️ Edit → Change question

🏆 Winning

1-2 players left = Winners!
Then:
🔄 Play Again
🏠 Go Home

💡 Strategy

✅ Good answers: Unique, creative, unexpected
❌ Bad answers: Common, blank, duplicates

Example: "Name a fruit"
❌ Apple (too common)
✅ Dragonfruit (unique!)

Be weird or be gone! 🎮✨
