How to Play – Odd One In

🎯 Objective

Stay unique! Everyone answers the same prompt. Common / duplicate answers are risky – the most "odd one in" survives.

📱 Setup

  • One player creates a room and becomes Game Master.
  • Everyone else joins using the shared link or room ID.
  • Each player uses their own phone – no screen sharing needed.

🔄 Round Flow

  1. Game Master taps Start Game.
  2. All players see the same question and a short "Get Ready" countdown.
  3. Timer starts (10s). Everyone types a single answer and submits.
  4. When time ends, all answers (including blanks) are locked in.
  5. Everyone moves to the review screen where the Game Master decides eliminations.

👑 Game Master Tools

  • Pause – Freeze the timer for all players.
  • Reset – Clear answers and restart the 10s timer.
  • Skip – Jump immediately to answer review.

🏆 Winning

The game continues until only 1–2 players remain. Those surviving players are crowned Odd One In champions.
